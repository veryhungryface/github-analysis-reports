“Google ADK/Cloud 에이전트 개발을 코딩 에이전트에게 맡기기 위한 작업 지침서”

직접 프레임워크를 대체하는 코딩 에이전트가 아니라, 기존 코딩 에이전트가 ADK 프로젝트를 잘 만들도록 하는 보조 도구입니다.

Python 3.11+uvNode.jsApache-2.0

1. 이 레포가 해결하는 문제

에이전트 개발에는 “프레임워크 지식”보다 “전체 생애주기 판단”이 더 어렵습니다

ADK로 에이전트를 만드는 것 자체보다 스캐폴딩, 테스트, 평가 데이터, 배포 타깃, 인증, 관측, 운영 규칙을 한 흐름으로 묶는 일이 어렵습니다. agents-cli는 이 과정을 CLI 명령과 스킬 문서로 묶어 코딩 에이전트가 따라 할 수 있게 합니다.

2. 작동 흐름

요청“문서 Q&A 에이전트를 만들어줘”처럼 목표를 전달
스킬 활성화workflow, scaffold, eval, deploy 등 맥락 주입
프로젝트 생성agents-cli scaffold로 ADK 템플릿 구성
품질 루프eval generate/grade/analyze/optimize로 개선
배포·운영Agent Runtime, Cloud Run, GKE, 관측까지 연결

3. 핵심 기능 카드

스캐폴딩

Python, Go, Java, TypeScript 기반 ADK 에이전트 템플릿과 배포/CI 구조를 빠르게 시작합니다.

평가 플라이휠

평가 데이터 생성, 추론 실행, 채점, 비교, 실패 분석, 프롬프트 최적화 흐름을 제공합니다.

배포 자동화

Agent Runtime, Cloud Run, GKE, Terraform, CI/CD 구성을 한 도구 안에서 안내합니다.

스킬 번들

코딩 에이전트가 ADK API, 배포, 관측, 등록 과정을 실수 없이 따르도록 7개 스킬을 제공합니다.

기존 코딩 에이전트 호환

Codex, Claude Code, Antigravity CLI 등과 함께 쓰도록 설계되어 도구 교체가 아니라 보강에 가깝습니다.

운영 관측

Cloud Trace, Cloud Logging, BigQuery 분석 등 운영 단계의 확인 루프를 함께 다룹니다.

5. 도입 판단

추천 대상

Google ADK로 실제 에이전트를 만들거나, Google Cloud 배포까지 고려하는 팀. 특히 “코딩 에이전트에게 반복 가능한 개발 절차를 맡기고 싶은” 팀에 적합합니다.

먼저 해볼 것uvx google-agents-cli setup 후 작은 샘플 에이전트를 만들고 eval grade까지 한 번 돌려보는 것이 좋습니다.

주의할 점

Google Cloud/ADK 중심 도구라서 비 Google Cloud 스택, 자체 에이전트 런타임, LangGraph 중심 프로젝트에는 직접 효용이 제한될 수 있습니다. 또한 Pre-GA 관련 고지가 있어 운영 도입 전 서비스 약관과 지원 범위를 확인해야 합니다.

6. SITPO 관점 메모

“스킬팩으로 에이전트 작업 품질을 끌어올리는 방식”이 참고 포인트입니다

웹사이트 클로너나 교육용 제작 파이프라인에도 비슷하게 분석·생성·검수·배포 스킬을 분리해 두면, 코딩 에이전트가 매번 임기응변하지 않고 정해진 품질 루프를 따라가게 만들 수 있습니다.
