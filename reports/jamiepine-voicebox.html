무엇을 도와주나?

Voicebox는 “말하기를 만드는 도구”와 “말을 텍스트로 넣는 도구”를 하나의 로컬 데스크톱/서버 제품으로 연결합니다. 제작자는 음성 샘플로 프로필을 만들고, 앱·스크립트·AI 에이전트는 API/MCP로 같은 음성 워크플로를 호출할 수 있습니다.

해결하는 문제

클라우드 음성 서비스 의존

상용 음성 복제·TTS·받아쓰기 도구는 계정, 요금제, 업로드된 음성 데이터 관리 부담이 큽니다.

분리된 음성 입출력 루프

TTS 생성, STT 받아쓰기, 후처리, 에이전트 음성 출력이 서로 다른 앱/API에 흩어지기 쉽습니다.

주요 사용 장면

콘텐츠 제작

내레이션, 팟캐스트, 대화형 스토리 초안 제작

개인 업무 입력

전역 단축키로 말하고 현재 텍스트 필드에 붙여넣기

앱 통합

게임 대사, 접근성 도구, 보이스봇에 REST API 연결

AI 에이전트

MCP-aware 에이전트가 로컬 음성으로 응답

음성 자산 관리

프로필, 캡처, 효과 체인, 생성 기록을 앱에서 관리

실행/구성 방식

데스크톱 앱

Tauri 기반 네이티브 앱으로 macOS·Windows 중심 배포, Linux는 소스 빌드 안내가 있습니다.

백엔드 서버

FastAPI 서버가 17493 포트에서 음성 생성, STT, 프로필, MCP/REST 기능을 제공합니다.

로컬/원격 추론

Apple Silicon MLX, CUDA/ROCm/DirectML/CPU, Docker 등 환경별 실행 경로를 제공합니다.

채택 전 확인할 점

시도 추천

음성 데이터 프라이버시가 중요하고, 로컬 GPU/데스크톱 환경에서 음성 생성·받아쓰기·에이전트 음성 출력을 함께 실험하려는 제작자/개발팀에 적합합니다.

먼저 검증

내 장비의 GPU/드라이버, 모델 다운로드 용량, 한국어 품질, 상업적 음성권리·초상권 정책, macOS 접근성 권한 UX를 실제 샘플로 확인해야 합니다.
