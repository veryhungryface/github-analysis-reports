이 레포가 해결하는 문제

Plaud에 쌓인 음성 기록을 수동으로 복사하지 않고, Obsidian 안에서 검색·연결 가능한 Markdown 지식 자산으로 정리합니다.

수동 정리 감소

녹음 제목, 날짜, 길이, 요약, 하이라이트, 전사를 노트 형식으로 렌더링합니다.

중복 없는 동기화

lastSyncAtMs 체크포인트와 file_id frontmatter로 새 녹음만 가져오고 기존 노트는 제자리 업데이트합니다.

개인 지식관리 연결

회의·인터뷰·메모 녹음을 Obsidian Vault 안의 일반 Markdown 파일로 남깁니다.

동작 흐름

핵심은 “녹음 목록 → 세부 콘텐츠 → Markdown 노트 → 다음 동기화 기준 갱신”입니다.

1. Plaud 녹음 목록 수집
↓
2. 휴지통 제외·신규 후보 선별
↓
3. 전사/요약 signed URL hydration
↓
4. Vault 폴더에 Markdown 생성/업데이트

사용자에게 유용한 기능

증분 동기화

최근 동기화 이후 녹음만 처리해 반복 실행 부담을 줄입니다.

풍부한 Markdown

AI 요약, 주요 하이라이트, 화자 라벨이 포함된 전사를 노트 본문에 배치합니다.

보안 토큰 저장

Obsidian Secret Storage API를 우선 사용하고, 불가 시 로컬 fallback을 사용합니다.

재시도/오류 분류

네트워크, rate limit, 5xx는 backoff로 재시도하고 인증 오류는 즉시 노출합니다.

설정 가능성

API 도메인, 동기화 폴더, 파일명 패턴, 시작 시 동기화, 기존 노트 갱신 여부를 조정합니다.

모바일도 가능

manifest 기준 isDesktopOnly: false, 최소 Obsidian 1.4.0 이상입니다.

채택 판단: “편리하지만 API 리스크 확인 필요”
