뭘 도와주나

로컬 LLM을 설치하고 실행하는 부담을 줄이면서, 파일 읽기·수정·셸 실행·스크립트 작성 같은 작업을 에이전트에게 맡기는 흐름을 제공해. 핵심 가치는 “개인 자료를 밖으로 보내지 않고도 AI 작업을 시도한다” 쪽에 있어

민감 자료 분석사내 코드, 개인 노트, 로그처럼 외부 API에 올리기 애매한 데이터를 로컬에서 다루는 용도
개발 보조코드 리뷰, 파일 검색, 자동 수정, 스크립트 생성 같은 CLI 기반 작업에 맞음
문서 자동화스킬을 붙이면 브라우저, 엑셀, PPT, PDF 같은 업무형 작업으로 확장 가능

작동 흐름은 단순해

사용자는 프로젝트 폴더에서 CLI를 실행하고, Magnitude는 하드웨어를 보고 적절한 모델 설정과 실행을 관리하는 구조야

입력파일, 코드, 로그, 문서, 이미지
로컬 추론Rust 기반 엔진이 모델 실행과 메모리 요구량을 관리
에이전트 작업셸 실행, 파일 편집, 스크립트 생성, 긴 세션 처리
결과분석, 수정안, 자동화 산출물, 정리된 문서

기술적으로 눈에 띄는 부분

자체 추론 엔진llama.cpp 기반 Rust 엔진을 포함하고, 모델 구성·메모리 계산·가속 설정을 다루는 게 차별점
모노레포 구조CLI, web, desktop, inference, SDK, agent runtime, provider 계층이 분리되어 있음
설계 문서 많음design·info 문서가 비교적 풍부해서 아직 빠르게 변하는 프로젝트지만 방향성은 읽기 쉬움
Bun + TypeScriptReact/OpenTUI 기반 CLI와 Effect-TS 중심 패턴을 사용함
테스트 흔적검색 기준 95개 테스트 호출이 확인되어, 최소한 CLI와 유틸 단위 검증은 진행 중
프리릴리스 단계최근 릴리스가 alpha 태그라 운영 도입보단 실험·검증에 가까움

누가 써보면 좋나

추천로컬 모델 기반 AI 에이전트를 직접 써보고 싶거나, 민감한 저장소·문서를 외부 API 없이 다루고 싶은 개발자에게 맞아
먼저 확인로컬 모델 성능, 하드웨어 메모리, macOS/Linux 환경, CLI alpha 안정성을 작은 프로젝트에서 먼저 봐야 해

빠른 시작: npm install -g @magnitudedev/cli 후 프로젝트 폴더에서 magnitude 실행

한 줄 판단

클라우드 API 기반 코딩 에이전트가 부담스럽고 “내 컴퓨터에서 사적인 자료까지 다루는 에이전트”가 필요하면 꽤 흥미로운 후보야. 다만 아직 alpha라, 바로 업무 핵심에 넣기보단 샘플 프로젝트로 모델 품질과 속도를 먼저 확인하는 쪽이 안전해
