WHAT PROBLEM IT SOLVES

시도 추천

  • 초등·중등 학습 개념 그래프가 필요한 팀
  • LLM 튜터/RAG에서 교육 토픽 구조가 필요한 경우
  • 자체 커리큘럼을 표준과 매핑하려는 연구·제품팀

먼저 확인

  • ODbL/CC BY-SA의 attribution·share-alike 의무
  • NGSS, C3, IB 등 일부 표준은 codes-only 또는 별도 권리 확인 필요
  • 내 서비스 국가/학년/과목 범위와 실제 샘플 매칭 품질
PRACTICAL FIRST TEST

도입 전 1개 단원으로 “토픽 → 선행개념 → 평가질문” 흐름을 검증하세요.

추천 첫 실험: 관심 과목의 20~50개 토픽을 골라 실제 교사용 커리큘럼이나 기존 문제은행과 매칭해보고, 선수관계가 학습 순서·진단 결과와 맞는지 확인합니다.
