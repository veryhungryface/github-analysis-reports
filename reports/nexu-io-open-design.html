이 레포는 무엇을 도와주나?

문제

AI 디자인 도구는 대개 클라우드/특정 모델/닫힌 워크플로에 묶여 있고, 실제 파일 시스템에서 반복 개선하기 어렵습니다.

해결

Open Design은 로컬 daemon, 웹/데스크톱 UI, Skill, 디자인 시스템을 묶어 이미 설치된 에이전트 CLI가 산출물을 직접 만들게 합니다.

입력 → 처리 → 산출물 흐름

1

브리프 입력

목표, 화면, 톤, 브랜드 맥락을 먼저 확정

2

Skill 선택

프로토타입, 덱, 마케팅, 운영 등 작업 유형 선택

3

에이전트 실행

Claude Code, Codex, Gemini 등 로컬 CLI/BYOK 엔진 사용

4

산출물 생성

HTML, PDF, PPTX, ZIP, MP4 등으로 미리보기·내보내기

누구에게 유용한가

제품팀

아이디어를 빠르게 UI 프로토타입/랜딩/덱으로 검증

디자이너

브랜드급 디자인 시스템과 템플릿을 기반으로 반복 제작

개발팀

실제 파일·로컬 도구·에이전트 런타임으로 산출물을 관리

오픈소스 사용자

BYOK·자가 호스팅·Apache-2.0 기반으로 락인 없이 실험

주요 장점

로컬 우선

프로젝트 폴더와 로컬 daemon을 중심으로 작업하고, 웹/데스크톱 인터페이스를 제공합니다.

에이전트 선택권

README 기준 16개 코딩 에이전트 CLI와 OpenAI 호환 BYOK 프록시를 지원합니다.

디자인 자산 풍부

31개 Skill, 72개 디자인 시스템, 미디어/프레임/템플릿 갤러리를 포함합니다.

채택 전 확인할 점

시도 추천

AI 기반 프로토타입·덱·랜딩 페이지를 빠르게 만들고, 로컬 에이전트 워크플로에 익숙한 팀에게 적합합니다.

먼저 검증

Node ~24, pnpm 10.33.x, 로컬 CLI 에이전트 설치 여부, 실제 팀 샘플 브리프로 산출물 품질을 확인하세요.

실행 판단

Open Design은 “디자인을 잘하는 단일 모델”보다 “로컬 에이전트 + Skill + 디자인 시스템 + 산출물 미리보기”를 하나의 제품 루프로 묶는 데 강점이 있습니다.

빠른 검증 방법: pnpm tools-dev로 로컬 실행 후, 실제 회사 브리프 하나로 랜딩/덱/모바일 프로토타입을 만들어 보세요.
