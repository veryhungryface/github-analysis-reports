이 레포는 무엇을 도와주나?

문제

AI가 애니메이션 JSON을 만들어도 실제 Lottie 런타임에서 잘 보이는지, 프레임·속성·배경을 빠르게 확인하기 어렵습니다.

해결

text-to-lottie Skill과 Vite 기반 플레이어를 묶어, 에이전트가 Lottie를 만들고 사용자가 로컬에서 즉시 재생·수정·검증할 수 있게 합니다.

입력 → 생성 → 검증 → 배포 흐름

1

근거 입력

SVG, 스크린샷, 데이터, 모션 지시를 프롬프트에 포함

2

에이전트 작성

Claude Code·Codex 등 코딩 에이전트가 Lottie JSON 생성

3

로컬 검증

Skia/Skottie 플레이어에서 재생, 프레임 고정, 슬롯 조정

4

멀티플랫폼 활용

Web, React Native, iOS, Android, Flutter에 JSON 배포

누구에게 유용한가

제품 디자이너

SVG 기반 마이크로 인터랙션을 빠르게 실험

프론트엔드팀

Lottie JSON을 앱/웹에 붙이기 전 로컬 확인

AI 워크플로 사용자

코딩 에이전트에게 애니메이션 제작 절차를 위임

모션 프로토타이퍼

프레임, FPS, easing, slot 제어를 빠르게 반복

교육/마케팅 제작자

설명용 애니메이션 초안을 JSON으로 확보

주요 장점

Skill 중심 제작법

저장소 안의 skills/text-to-lottie/SKILL.md가 Skottie 호환 JSON 작성 규칙과 검증 절차를 안내합니다.

검증 가능한 플레이어

public/lottie.json을 읽어 CanvasKit/Skottie로 렌더링하고, URL frame 고정·재생 컨트롤·줌을 제공합니다.

속성 조정 흐름

슬롯/컨트롤 패널로 색상·수치·텍스트 같은 slottable property를 실시간으로 조정하고 내보낼 수 있습니다.

채택 전 확인할 점

시도 추천

“프롬프트 → Lottie JSON → 로컬 검증 → 앱/웹 삽입” 흐름을 빠르게 만들고 싶은 팀에게 적합합니다.

먼저 검증

자체 SVG/브랜드 모션 샘플 하나로 Skottie 렌더링 호환성, 텍스트/slot 처리, 실제 앱 런타임 재생 품질을 확인하세요.
