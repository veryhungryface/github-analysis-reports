뭘 도와주나

일반 STT가 종종 지워버리는 filler, 반복, false start, vocal sound를 데이터로 남기고 싶을 때 유용해. 같은 음성에서 말한 그대로의 전사와 읽기 좋은 전사를 선택할 수 있어서 연구·의료 음성 분석·TTS 데이터 구축에 맞아

그대로 전사[um], 반복, 끊긴 말, 웃음 같은 실제 발화 흔적을 보존하는 쪽에 강점
깨끗한 전사필요할 땐 intended 모드로 숫자·날짜·문장을 읽기 좋게 정리
단어 시간표README 기준 단어 경계 오차가 약 30ms 수준이라고 제시됨

작동 흐름은 이렇게 보면 돼

오디오를 넣고 전사 모드를 고른 뒤, 단어 단위 타임라인과 결과 텍스트를 받아 분석·자막·데이터셋 작업에 쓰는 구조야

음성 파일회의, 인터뷰, 임상 음성, 녹음 자료
모드 선택verbatim 또는 intended
정렬word timestamps, forced alignment, longform 처리
활용자막, 연구 분석, TTS 데이터셋

기술적으로 눈에 띄는 부분

두 백엔드CTranslate2 기반 fast path와 HuggingFace Transformers 기반 portable path를 선택 가능
긴 오디오 처리30초 단위 경계에서 중복·누락이 생기지 않도록 continuation 전략을 제공
Verbatimize이미 믿을 만한 깨끗한 자막이 있을 때 실제 발화 흔적만 삽입하는 기능이 특이함
추측 디코딩ct2 backend에서 draft model을 써서 README 기준 1.3~1.4배 빠른 경로 제공
환각 완화Whisper 계열의 반복 루프 문제를 감지·억제하는 디코딩 완화책 포함
문서 밀도DOCS.md가 1천 줄 넘게 API, 설치, longform, 정렬, 라이선스 caveat를 설명함

누가 써보면 좋나

추천발화 습관, 침묵 주변 말, 반복·말더듬, 의료·상담·인터뷰 원자료처럼 “말한 방식”이 중요한 팀에게 잘 맞아
먼저 확인상업용이면 모델 가중치 라이선스를 꼭 확인해야 해. 코드 MIT와 모델 라이선스가 다르다는 점이 핵심 리스크야

빠른 시작: pip install "crisperwhisper[ct2]" 또는 pip install "crisperwhisper[transformers]"
