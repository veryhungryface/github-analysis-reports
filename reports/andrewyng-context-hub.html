문제는 “에이전트가 문서를 기억하지 못한다”는 점입니다.

LLM 코딩 에이전트는 오래된 예제, 검색 결과 노이즈, 세션 종료 후 사라지는 시행착오 때문에 API 사용을 잘못 작성하기 쉽습니다. Context Hub는 검수된 문서와 로컬 주석을 CLI로 가져오게 해 이 문제를 줄입니다.

API 환각 감소최신 문서와 언어별 예제를 우선 읽게 합니다.
토큰 절약필요한 문서나 reference 파일만 가져오는 증분 fetch를 지원합니다.
경험 재사용로컬 annotation으로 “지난번에 막힌 점”을 다음 작업에 남깁니다.
사용 흐름

검색 → 가져오기 → 적용 → 피드백의 단순 루프입니다.

검색chub search
문서 선택ID/언어/버전
가져오기chub get
코딩 적용Markdown 읽기
주석·피드백다음 작업 개선
누구에게 맞나

개인보다 “에이전트를 반복 운영하는 팀”에서 가치가 큽니다.

AI 코딩 에이전트 운영자Claude Code, Codex, Cursor류 에이전트가 매번 같은 문서를 안정적으로 보게 만들고 싶을 때 유용합니다.
SDK/API 문서 관리자LLM이 읽기 쉬운 문서 패키지를 Markdown+frontmatter로 공개·개선할 수 있습니다.
팀 표준화 담당자사내 API/관례 문서를 로컬 소스로 빌드해 팀 에이전트에 공급하는 흐름을 실험할 수 있습니다.
채택 전 확인

좋은 후보지만, 실제 프로젝트 샘플로 검증해야 합니다.

먼저 해볼 것

npm install -g @aisuite/chub 후 자주 쓰는 API를 chub search, chub get으로 가져와 에이전트가 바로 쓸 수 있는지 확인하세요.

주의할 점

공개 문서 커버리지, 사내 문서 배포 방식, annotation을 untrusted input으로 다루는 운영 규칙을 먼저 정해야 합니다.

저장소 신호

문서 저장소이면서 CLI와 MCP 진입점까지 포함합니다.

루트는 content/에 대량의 문서 패키지를 담고, cli/ 워크스페이스가 chub 및 chub-mcp 실행 파일을 제공합니다. 현재 얕은 클론 기준 파일 약 1,855개, DOC.md 약 1,703개, Markdown 약 57.9만 줄 규모입니다.
